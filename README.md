# TradeFlow Analytics

Интерактивное Streamlit-приложение для исследования межрегиональных поставок продовольствия и зерна. Оно объединяет несколько Excel-файлов, очищает агрегаты, визуализирует товарные потоки и рассчитывает индексы влияния регионов в торговой сети.

> Приложение запускается с синтетическим демо-набором, поэтому интерфейс можно оценить сразу — реальные данные для первого запуска не нужны.

## Возможности

- объединение нескольких Excel-файлов с одинаковой структурой;
- фильтрация по единице измерения, товару и регионам-поставщикам;
- обзор объёма, числа связей и охвата регионов;
- рейтинг регионов-получателей по объёму поставок;
- расчёт прямых индексов `wBI₁`, нормированного `wBI₁` и `wBI₂` с квотой в долях входящего потока или в абсолютных единицах;
- поиск критических групп поставщиков;
- анализ непрямого влияния для путей длиной от 2 до 5;
- сравнение прямого и непрямого влияния;
- экспорт рассчитанных индексов и отфильтрованных потоков в CSV.

## Быстрый старт

Требуется Python 3.10 или новее.

```bash
git clone https://github.com/Nestorbi219/streamlit_app.git
cd streamlit_app
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

После запуска откройте адрес, указанный Streamlit — обычно это `http://localhost:8501`.

## Формат входных данных

Приложение принимает файлы `.xlsx` Росстата «Межрегиональная торговля основными пищевыми продуктами и зерном» и ожидает следующую структуру:

1. первые три строки пропускаются;
2. четвёртая строка содержит товар и единицу измерения через запятую («Мука, тонна»); объединённые ячейки допустимы;
3. пятая строка содержит регионы-**поставщики** (вывоз);
4. первый столбец содержит регион-**получатель** (ввоз);
5. остальные ячейки — объёмы поставок.

Это ориентация, указанная в самих таблицах Росстата: «по горизонтали располагаются субъекты, откуда производится вывоз товаров; по вертикали — субъекты, куда осуществляется ввоз». Из сети исключаются РФ, федеральные округа и составные субъекты «Архангельская область» и «Тюменская область» (их части — НАО, ХМАО, ЯНАО и др. — остаются отдельными узлами), так что каждый поток учитывается один раз. Поскольку объёмы разных товаров измеряются в разных единицах, сеть строится по товарам одной единицы измерения (по умолчанию — тонны).

Можно загрузить несколько файлов одновременно. Их строки будут объединены, а показатели — пересчитаны по общему набору.

## Как читать индексы

- **wBI₁** показывает влияние критических групп поставщиков относительно общего входящего потока конкретного региона.
- **wBI₁ (норм.)** = wBI₁ / 2^(m−1), где m — число учтённых поставщиков. Это верхняя граница wBI₁, поэтому нормированный индекс лежит в [0, 1] и сравним для регионов с разным числом поставщиков.
- **wBI₂** сопоставляет то же влияние с суммарным весом всей торговой сети.
- **Квота** — порог, при котором группа поставщиков считается критической: доля α входящего потока региона (по умолчанию 50%) или абсолютный объём `q`.
- **Размер минимальной критической группы** — сколько крупнейших поставщиков в сумме обеспечивают не меньше квоты.
- **Непрямое влияние** строится по правилу max–min: для каждой пары регионов выбирается путь с максимальным значением самого слабого ребра. Квота на графе непрямого влияния берётся от прямого ввоза региона.

Количество возможных групп равно `2ᴺ − 1`, поэтому приложение ограничивает анализ 15 крупнейшими входящими поставщиками региона. Непрямой расчёт выполняется без отсечения путей и на плотной сети может быть ресурсоёмким.

## Ограничения

- формат Excel должен соответствовать описанной двухуровневой шапке;
- товары в разных единицах измерения не суммируются: анализ ведётся в одной единице;
- демо-данные синтетические и не предназначены для содержательных выводов;
- расчёт непрямого влияния для больших плотных графов может потребовать значительных ресурсов.
